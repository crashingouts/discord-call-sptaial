# Visual comparison captures

Every image here is a headless Chrome screenshot at the reference captures' own size (1024x572),
with simulated participants: names, portraits and control labels are stand-ins, not a real call.

| File | What it is |
| --- | --- |
| `before-selected.png`, `before-overview.png` | The scene as it rendered before this change: previous `style.css` (`_old-style.css`, kept here to keep the pair reproducible) and previous `layout.ts` positions, same 14 participants. |
| `after-selected.png`, `after-overview.png` | The scene now. Rendered from `style.preview.html?state=…&bare=1`, whose positions are generated by `layout.ts` and checked by `style.test.ts`. |
| `compare-selected.png`, `compare-overview.png` | The user's reference image beside the current render, same size, labelled. |
| `themes-grid*.png` | The nine-theme grid the old harness drew, now with the reference backdrop layers. |

Reproduce an "after" capture:

```
chrome --headless=new --window-size=1024,572 --screenshot=out.png \
  "file:///<repo>/src/userplugins/spatialVoice/style.preview.html?state=selected&bare=1"
```
